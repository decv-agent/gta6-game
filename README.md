PALMERA HEAT — an original top-down open-world crime game set in the sun-soaked streets of Palmera City. Explore on foot or steal any car, run a three-mission story for courier Rico Sol, and outrun a five-star police response. Traffic, pedestrians, a wanted system, combat, a full HUD with a live minimap — all in plain static files, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
